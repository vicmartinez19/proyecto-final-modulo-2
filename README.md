# 🐾 Mundo Animal - Landing Page Responsiva

## Descripción
Este proyecto es una landing page profesional dedicada a la educación y conservación de la fauna silvestre. Es el **Proyecto Final** del módulo de Desarrollo Web, diseñado para demostrar el dominio de la estructura semántica, el diseño adaptable y la gestión de estilos avanzados con CSS.

## Tecnologías Utilizadas
* **HTML5 Semántico:** Estructura organizada para accesibilidad y SEO.
* **CSS3:** Estilos personalizados, incluyendo el uso de variables (`:root`).
* **Flexbox:** Sistema principal de maquetación para componentes dinámicos.
* **Diseño Responsivo:** Estrategia *Mobile-First* con Media Queries.
* **Git & GitHub:** Control de versiones y despliegue mediante GitHub Pages.

## Características del Proyecto
1. **Navegación Adaptable:** Un menú que se transforma de una lista vertical en móviles a una barra horizontal en escritorio.
2. **Sección Hero Impactante:** Uso de unidades de Viewport (`vh`) para garantizar que la bienvenida ocupe el espacio visual correcto en cualquier pantalla.
3. **Cuadrícula de Especies (Cards):** Implementación de una sección de tarjetas que cambia de 1 a 3 columnas usando Flexbox.
4. **Formulario de Contacto:** Formulario funcional con validaciones nativas de HTML5 para captar voluntarios o donaciones.
5. **Banner de Cookies:** Elemento con posicionamiento fijo (`fixed`) y gestión de capas mediante `z-index`.
